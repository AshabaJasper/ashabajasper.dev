# Website standard checklist

Status of ashabajasper.dev against the owner's 20-item website standard, for all three
hosts: portfolio (`ashabajasper.dev`, `www` redirects to it), blog
(`blog.ashabajasper.dev`) and admin (`admin.ashabajasper.dev`).

Last reviewed: 7 October 2026, during the initial build, before the first deploy.

Status values:

- **PASS**: verified in a rendered browser or on production, with the evidence named.
- **MISSING/BLOCKED**: not done, blocked on an owner input, or built but not yet
  verified. "Awaiting verification" means the implementation exists or is in progress
  at the paths named, and nobody has yet checked it rendered at the required widths or
  on production. A successful build alone is not a PASS.
- **NOT APPLICABLE**: does not apply, with the reason recorded.

Paths are the intended implementation. Update this file with the observed result (route,
width, theme, command output) when each item is verified, and keep it current whenever a
change touches an item.

## Launch blockers and owner inputs

Facts and actions only the owner can supply. Pages leave these out until they exist; none
is filled with a guess.

1. **Years of experience**, if the portfolio should state it.
2. **Outcome numbers** for work entries (optional): only real, attributable figures.
3. **A fresh Coolify API token** created on the VPS, if deployments are to be automated
   or checked through the API. Never commit it.
4. **Umami admin password**: change the default immediately after installing Umami
   (DEPLOYMENT.md section 8), then add the website and set its id.
5. **SMTP or Telegram details**, only if email or Telegram notifications are wanted. The
   site works without them; messages stay in the admin inbox.
6. **Complete `/setup`** at `https://admin.ashabajasper.dev/setup` with `SETUP_TOKEN`,
   then remove `SETUP_TOKEN` from Coolify (DEPLOYMENT.md section 7).
7. **Retention periods** for contact messages and comments, if the privacy page is to
   state a period beyond "until deleted by the owner".
8. **Licence for code samples in posts**: confirm MIT (proposed) or another licence
   before the terms page or any post states one.
9. **GitHub repository**: confirm the name `AshabaJasper/ashabajasper.dev`, that it is
   public, and that `main` is the deploy branch. The local checkout has no remote yet.
10. **The `os` DNS record**: confirm whether it is wanted; it is not a domain of this
    application (DEPLOYMENT.md section 2).
